## How to open
Double-click **`index.html`** — it opens in any browser. Needs an internet connection the
first time (the three brand fonts load from Google Fonts).

## How to print / export to PDF
1. Open `index.html`, press **Ctrl+P**.
2. **Destination:** *Save as PDF* (or your printer).
3. **Paper size:** A4 · **Margins:** None · **Scale:** Default (100%).
4. **Tick “Background graphics”** ← important. Without it the cream pages and the dark
   panels print white. This is the one setting people forget.

The CSS already pins A4, zero page margin, and a page break after every section, so each
of the 12 sections lands on its own page.
