# בית הפרוטוקולים — GT Everyday

> הבית של כל הפרוטוקולים התפעוליים של המפעל והחברה.
> פרוטוקולים כאן הם **חיים**: הם משתפרים עם הזמן, מתועדים בגרסאות, ו**מתחשבים אחד בשני** —
> כשאחד משתנה, בודקים את אלו שתלויים בו כדי שלא ייווצרו סתירות.

---

## מהו פרוטוקול כאן

פרוטוקול = הדרך המוסכמת והמדויקת שבה משהו נעשה בחברה, מקצה לקצה — מי עושה, מה, באיזה סדר,
ומה קורה כשמשהו חורג. לא רשימת כוונות; **התהליך התפעולי האמיתי** שאפשר להדפיס, לתלות, ולתת לאדם חדש שיבצע בלי ניחושים.

כל פרוטוקול חי בתיקייה משלו תחת `protocols/`, ובתוכה:

| קובץ | מה זה |
|---|---|
| `README.md` | מטא‑דאטה: בעלים, סטטוס, גרסה, סיכום הצעדים, פרוטוקולים קשורים, יומן שינויים. **מקור האמת.** |
| `protocol.html` | הגרסה היפה והמלאה (RTL, צבעונית) — המקור שעורכים. |
| `protocol.pdf` | הגרסה להדפסה / שיתוף, מרונדרת מתוך ה‑HTML. |
| קבצים נלווים | מדריכים / טפסים ספציפיים לפרוטוקול (למשל `format-guide.md`). |

## איך פרוטוקול מתפתח (דינמי)

1. **גרסאות** — כל פרוטוקול נושא מספר גרסה (`major.minor`). שינוי נוסח/הבהרה = `minor`. שינוי שמשנה את מה שאנשים עושים בפועל = `major`.
2. **יומן שינויים** — כל שינוי נרשם בתחתית ה‑`README.md` של הפרוטוקול: תאריך · גרסה · מה השתנה · מי אישר.
3. **מקור האמת** — עורכים את `protocol.html`, מרנדרים מחדש את ה‑PDF, ומעדכנים את ה‑`README.md` (גרסה + יומן). שלושתם נשארים מסונכרנים.
4. **בעלים** — לכל פרוטוקול יש בעלים אחד שאחראי שהוא נכון ומעודכן.

## "מתחשבים אחד בשני" (הכלל המרכזי)

פרוטוקולים לא חיים בבועה. כל `README.md` כולל סעיף **פרוטוקולים קשורים** — מי תלוי בי ובמי אני תלוי.

- כשמשנים פרוטוקול, **עוברים על הפרוטוקולים הקשורים** ומוודאים שאין סתירה (אותו שלב מתואר אחרת, אותו מונח פירושו שונה).
- מונח/מספר שמופיע בכמה פרוטוקולים (למשל "עד 14:30", "ניילונית במקום הייעודי") — אם משתנה באחד, מתעדכן בכולם.
- פרוטוקול חדש שנוגע בקיים — מוסיפים הפניה הדדית בשני ה‑`README`.

## איך מוסיפים פרוטוקול חדש

1. מעתיקים את [`_TEMPLATE.md`](_TEMPLATE.md) לתיקייה חדשה `protocols/<kebab-name>/README.md`.
2. ממלאים מטא‑דאטה, סיכום צעדים, ופרוטוקולים קשורים.
3. בונים `protocol.html` יפה (סקיל `frontend-design`) ומרנדרים ל‑`protocol.pdf`.
4. מוסיפים שורה לטבלת **אינדקס הפרוטוקולים** למעלה, ומחברים הפניות הדדיות לפרוטוקולים קשורים.
