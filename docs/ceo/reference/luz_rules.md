# חוקי לו״ז — Chief-of-Staff OS

> ולידציה **חוסמת**: `day-close` ⊥ מסתיים עד שכל חוק כאן עובר. חוק נופל ⇒ לתקן את ההצעה ולהריץ שוב, ⊥ לכתוב ליומן ולהתנצל.
> ״אבנים לפני חצץ״ (Covey) + ״מיקוד אחד״ (Drucker) — מתורגמים לכללים מכניים.

## היומן — נעול 2026-08-01 (גריל טום)

**יומן יעד: `tom@gteveryday.com` (הראשי).** אין יומן ייעודי — לקונקטור היומן **אין** יכולת ליצור יומן חדש (קיימים רק `tom@gteveryday.com` ו-Holidays in Israel, אומת חי 2026-08-01). ∴ הבלוקים חיים ביומן הראשי עם תווית מזהה.

**כל אירוע שקלוד יוצר ! יישא:**
- כותרת בקידומת **`GT · `** — למשל `GT · אבן 1 · פרוטוקולים למקסים`
- בגוף (`description`) שורה ראשונה: **`[cos-os] type=<deep|batch|task|rock> week=<YYYY-MM-DD>`**
- `colorId`: **`9`** (Blueberry) לבלוק עומק/אבן · **`8`** (Graphite) לבלוק אצווה · **`5`** (Banana) להכנה לפגישה

**חוק הבעלות:** קלוד קורא, מזיז ומוחק **רק** אירועים שגופם מכיל `[cos-os]`. אירוע בלי הסמן = של טום או של מישהו אחר ⇒ ⊥ לגעת, גם ⊥ להזיז. הפרה = `assumption_failure`.

⊥ להזמין משתתפים לבלוקים האלה. הם חסימות זמן אישיות, ⊥ פגישות.

## חוקי הבנייה

| # | חוק | בדיקה מכנית |
|---|---|---|
| L1 | **בלוק עומק אחד מאוחד ≥90 דק׳** ביום | ∃ בלוק `type=deep` באורך ≥90; ⊥ שני בלוקים של 45 |
| L2 | **אבן היום ראשונה** — הבלוק הראשון של יום העבודה שייך לאבן, ⊥ לדחוף | `min(start)` מבין בלוקי `[cos-os]` ⇒ `type ∈ {deep, rock}` |
| L3 | **אצוות במקום טפטוף** — מיילים/הודעות ב-≤2 בלוקים קבועים | `count(type=batch) ≤ 2`, כל אחד ≤45 דק׳ |
| L4 | **⊥ overbooking** — אפס חפיפה עם אירוע קיים ביומן | `list_events` על היום; כל בלוק חדש ⊥ חותך אף אירוע קיים |
| L5 | **ריאליזם** — ≤5 בלוקי `[cos-os]` ביום, ≤6 שעות מתוזמנות סה״כ | ספירה + סכימה |
| L6 | **∀ אבן ⊇ בלוק אחד בשבוע** — אבן בלי בלוק היא משאלה | לכל אבן בכרטיס השבוע ∃ בלוק אחד לפחות עד סוף השבוע |
| L7 | **שעות עבודה** — בלוקים רק 07:00–18:00 IL, א׳–ה׳ | גבולות + `weekday ∈ 0..4` |
| L8 | **חיץ 15 דק׳** בין בלוק לבלוק | `start[i+1] − end[i] ≥ 15min` כשהם רצופים |

**שישי/שבת: שקט מלא** (נעול 2026-08-01). ⊥ בלוקים, ⊥ day-open, ⊥ day-close. רק המוצ״ש שובר את השקט.

3. שים בלוק אצווה אחד אחה״צ; שני רק אם יש ≥8 פריטים ממתינים.

5. הרץ L1–L8. נפילה ⇒ חזור ל-2 עם פחות.

## שער טום
