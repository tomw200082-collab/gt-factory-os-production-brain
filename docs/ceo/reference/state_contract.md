## כללי אי-שכפול

1. **⊥ להעתיק מספר ממערכת חיה למסמך.** להצביע על השאילתה. מספר במסמך = תמונה מתה ברגע שנכתבה.
2. **המראה `registry.md` ⊥ מקור.** סתירה בין המראה לנושן ⇒ **נושן מנצח**, המראה נכתבת מחדש. ⊥ לפתור לכיוון השני.
3. **כרטיס השבוע = בעלים יחיד לאבנים.** הגרדיאן קורא, ⊥ כותב.
4. **הלו״ז חי ביומן, ⊥ בכרטיס.** הכרטיס מחזיק כוונה (אבנים); היומן מחזיק זמן.
5. עובדה בלי בעלים ברור בטבלה ⇒ ⊥ להמציא מקום. לשאול את טום.
