### קיבוץ סטטוס (מבנה `status` בנושן)

`to_do` = {`לא התחיל`} · `in_progress` = {`בתהליך`, `בהמתנה`} · `complete` = {`הושלמו`, `בוטל`}.
**פעיל** ≡ `סטטוס ∈ {לא התחיל, בתהליך, בהמתנה}`. **סגור** ≡ `∈ {הושלמו, בוטל}`.

## חישובים — ⊥ לגזור מחדש כל פעם

`today` = תאריך IL של הריצה.

| מדד | הגדרה |
|---|---|
| **עיכוב** (פרויקט) | פעיל ∧ `end < today` ⇒ `days_late = today − end`. אחרת 0. |
| **מזדקנת** (משימה) | פתוחה (`תאריך השלמה IS NULL`) ∧ `תאריך יעד < today` ⇒ `days_overdue`. |
| **תקוע** (GTD) | פרויקט פעיל ∧ **אפס משימות פתוחות** (כל המשימות המקושרות סגורות, או אין בכלל). ⇐ ״פרויקט פעיל בלי next-action״. **מסומן בכל מוצ״ש.** |
| **waiting-on** | משימה פתוחה ∧ `בעל תפקיד` ⊅ `תום` ⇒ ממתינה לאדם אחר. `checkback` = `תאריך יעד`; עבר ⇒ צף. |
| **עומס פר-אדם** | `count(*)` משימות פתוחות group by `בעל תפקיד` (multi — פריט נספר לכל בעליו). |
| **התקדמות** | `סגורות / סה״כ` על המשימות המקושרות. ⊥ לקרוא את ה-rollup. |

## מתכוני קריאה — להעתיק כמו שהם

**גאנט מלא (פרויקטים לפי עדיפות):**
```sql
SELECT "שם", "סטטוס", "עדיפות", "ציר", "מסלול", "KPI",
       "date:לוח זמנים לפרויקט:start" AS start,
       "date:לוח זמנים לפרויקט:end"   AS fin,
       "חסימה על ידי" AS blocked_by, "משימות" AS tasks, url
FROM "collection://cb704298-2afb-8226-9b23-876996b62c5d"
WHERE "סטטוס" NOT IN ('הושלמו','בוטל')
ORDER BY "עדיפות" ASC
```

**משימות פתוחות (מזדקנות קודם):**
```sql
SELECT "שם", "בעל תפקיד", "גל", "מסלול",
       "date:תאריך יעד:start" AS due, "פרויקטים" AS proj, url
FROM "collection://c6604298-2afb-8258-8026-87e9538244c3"
WHERE "date:תאריך השלמה:start" IS NULL
ORDER BY due ASC NULLS LAST
```

**מה נסגר בשבוע האחרון (לרטרו):**
```sql
SELECT "שם", "בעל תפקיד", "date:תאריך השלמה:start" AS done, url
FROM "collection://c6604298-2afb-8258-8026-87e9538244c3"
WHERE "date:תאריך השלמה:start" >= date('now','-7 days')
ORDER BY done DESC
```

**waiting-on שהבשיל היום:**
```sql
SELECT "שם", "בעל תפקיד", "date:תאריך יעד:start" AS due, url
FROM "collection://c6604298-2afb-8258-8026-87e9538244c3"
WHERE "date:תאריך השלמה:start" IS NULL
  AND "בעל תפקיד" NOT LIKE '%תום%'
  AND "date:תאריך יעד:start" <= date('now')
ORDER BY due ASC
```

## מתכוני כתיבה — אומתו חי 2026-08-01 (כתיבה → קריאה → היפוך → קריאה)

**סימון בוצע** — `notion-update-page` · `command: update_properties`:
```json
{ "date:תאריך השלמה:start": "YYYY-MM-DD", "date:תאריך השלמה:is_datetime": 0 }
```
⊥ ללחוץ על ה-button `בוצע` (⊥ נגיש ל-API). מילוי `תאריך השלמה` **הוא** הסימון — ה-rollup `התקדמות` מתעדכן ממנו.

**קישור לפרויקט** (relation, limit 1) — מערך עם URL אחד:
```json
{ "פרויקטים": ["https://app.notion.com/<page_id_ללא_מקפים>"] }
```

**ניקוי ערך:** `null`. אומת — מחזיר את השדה ל-NULL.

**משימה חדשה** — `notion-create-pages`, `parent: {type:"data_source_id", data_source_id:"c6604298-2afb-8258-8026-87e9538244c3"}`:
```json
{ "שם":"…", "בעל תפקיד":["תום"], "גל":"מנהלה", "מסלול":"מנהלה",
  "date:תאריך יעד:start":"YYYY-MM-DD", "date:תאריך יעד:is_datetime":0 }
```

**עדכון סטטוס פרויקט:** `{ "סטטוס": "בתהליך" }` — מחרוזת מהרשימה הסגורה בלבד.
