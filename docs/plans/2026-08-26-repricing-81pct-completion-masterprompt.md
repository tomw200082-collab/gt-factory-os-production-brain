## §5 — Landmines

Each is a defect that was actually hit in this work on 2026-08-25/26.

1. **A structured read of 6 pages exceeds the tool's token cap.** *Symptom:* the call
   returns an "exceeds maximum allowed tokens" error with a saved file path — and the
   transaction was still opened, so the `transaction_id` is stranded inside that file.
   *Cause:* full CDF for a drink page is roughly 10k tokens. *Resolution:* let it
   overflow on purpose, then parse the saved file with a script — extract only the
   `transaction_id` and the four `locator_id`s per page. This keeps the bulk output out
   of context entirely and is the only reason this job is tractable. A working parser is
   in the git history of this branch.

2. **Element ids are not shared between pages.** *Symptom:* an `element_ids` filter using
   ids from another page returns an empty `elements` array. *Cause:* Canva regenerates
   ids per page. *Resolution:* read every page for its own ids. Verified on pages 9 and
   44 — zero matches.

3. **The asterisk is not uniform.** *Symptom:* a page gains or loses `*` on its cost.
   *Cause:* pages 8, 16, 17, 18 carry none; the other 44 do. *Resolution:* take the
   asterisk from the figures file's `star` field, and confirm against the page's current
   cost string before writing.

4. **`edit-design` returns the whole page document.** *Symptom:* context fills fast.
   *Cause:* no way to suppress it. *Resolution:* budget for it — roughly 13k tokens per
   page — and commit often so a context exhaustion does not lose uncommitted work.

5. **The `שוליים מוצע` column in `foodcost_proposal.csv` uses the wrong formula.**
   *Symptom:* margins 2–5 points higher than the figures file. *Cause:* it divides by
   the VAT-inclusive price. *Resolution:* never read margins from that column. It is
   kept only for provenance. `drinks-pricelist/SKILL.md` says so too.

6. **Canva's export host is blocked by this environment's egress proxy.**
   *Symptom:* `curl` on `export-download.canva.com` returns `403 CONNECT`. *Cause:*
   policy denial, confirmed at `$HTTPS_PROXY/__agentproxy/status`. *Resolution:* you
   cannot download the exported PDF to inspect it. Verify through `read-design` instead,
   and ask the owner to check file size himself.
