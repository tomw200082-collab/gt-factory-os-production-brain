## 0. Headlines

- 5 live screens + `/apps` switchboard behind one gate `<RoleGate minimum="sales:execute">` (`src/app/(sales)/layout.tsx:43`); `sales_rep`, `planner`, `admin` all see and write everything incl. Attention and Settings. **No "manager" role**; `admin` alone holds `sales:execute+override`, unchecked in `(sales)`.
- **Lead detail is a drawer only** (`LeadDrawer`), mounted on `/sales/leads` and `/sales/attention`. A Today card cannot open its lead (only `tel:` / `wa.me`).
- **No task entity today.** Work is derived at read time by `api_read.v_sales_today`; the only promise field is `lead.next_touch_at`; history is `sales_core.lead_event`. Event-sourced tasks are planned (GT Pulse A, tranche 185; `_active.txt` still says `184` on main; `safe-redirect.ts` absent on main).
- "GT Pulse" appears nowhere in this repo's code or docs on main.
- **The workspace sends nothing to customers**: every outbound action is a human hand-off (`tel:`, `wa.me`, `mailto:`, `_lib/wa.ts:1-6`). No "send portal link" action exists in the sales workspace (login links for approved customers are minted at `/admin/portal-registrations`).
- **Seven backend event types have no Hebrew label**: `draft_order`, `auto_message`, `button_tap`, `opt_out`, `qualified`, `kit_sent`, `question_logged` render as raw tokens (`EventTimeline.tsx:75`, `ActivityFeed.tsx:38`).
- Deep links `?lead=` / `?org=` work signed-in but are lost on the login bounce (`middleware.ts:151` uses `pathname` only; `login/page.tsx:415` redirects unvalidated).

## 3. Queue, Today, Attention

`v_sales_today` (0326:161-218): `conversion` (won + `converted` within 7 days) · `returning_customer` (new, untouched, org has Shopify id/snapshot) · `new_lead` (new, untouched, not customer, contactable) · `due_follow_up` (new/working, `next_touch_at <= now()`); uncontactable non-customers excluded. Sort: conversion 0, returning 1, due 2, new 3; due by `next_touch_at` asc; then `coalesce(next_touch_at, created_at)` desc (`newest_first`). `?assignee=X` returns `assignee = X OR assignee IS NULL`. Daily cap client-side on `new_lead` only (default 15; deferred rows counted: "היום: N שיחות · עוד M ממתינות בתור"); rule sentence `UI.dailyCapRule` "מתוך מכסה יומית של N לידים חדשים · מעקבים שהתחייבת אליהם אינם נספרים"; age red past `sla_hours/24`. "Depth system" (#219) = card shadow + sheen + themed selection only. Attention buckets (`v_sales_attention` 0326:258-311): overdue (`next_touch_at < now`), unowned (open, unassigned, untouched, >3 days, contactable), stalled (working, no event in 14 days).
