# מה סוגרים — מחסן תוויות

> סוגר: **מקסים** · מתי: סוף כל יום
> **גרסה 29.7.2026**

הדף המודפס תלוי במחסן כדי שתדע **מה בודקים**. הסימון עצמו נעשה במערכת, בדף שלך.

## מלאי

- כל סוג במקום הקבוע והמסומן שלו
- נרשם מי מתחת למלאי המינימום

## סדר

- תוויות שלא בשימוש — מוצר שירד או עיצוב ישן — בצד ומסומנות

## שים לב

מלאי המינימום של כל תווית = שלושה שבועות ייצור של אותו מוצר, לפי התחזית או תכנון הייצור. הכמות משתנה מתווית לתווית — הזמן לא. מזמינים בגלילים של 500, תמיד מעגלים כלפי מעלה.

## עוצרים ומתקשרים
