# Dark Mode Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a per-user, manually-toggled, DB-synced light/dark theme to the GT Factory OS portal. All surfaces respect the toggle. The "Operational Precision" design system is preserved in dark mode (warm graphite, not OLED black; petrol teal lifted, not generic blue).

**Architecture:**
1. Backend (`gt-factory-os`): one migration adds `theme_preference text` to `app_users`; one new endpoint `POST /api/v1/mutations/me/set-theme`; existing `GET /api/v1/queries/me` extended to surface the field.
2. Portal (`window2-portal-sandbox`): Tailwind tokens migrate from static HSL to `hsl(var(--token))` references; CSS variables defined twice in `globals.css` — once on `:root` (light), once on `:root.dark` (dark); a `ThemeProvider` client component reads `theme_preference` from session and toggles `<html class="dark">`; `UserIndicator` in `TopBar` becomes a real `DropdownMenu` with a "Dark Mode" item.

**Tech Stack:** Postgres 16 + pgTAP + Kysely (backend); Next.js 15 App Router + Tailwind 3.4 + Radix DropdownMenu + lucide-react (portal). Existing ones — no new heavy deps.

**Cross-repo work:** Tasks 1–3 land in `C:/Users/tomw2/Projects/gt-factory-os/`. Tasks 4–15 land in `C:/Users/tomw2/Projects/window2-portal-sandbox/`. Tom decides commit/PR cadence per repo; the plan does not couple them.

**Locked decisions** (from brainstorming 2026-04-28; do not re-litigate):
- Q1 **Surfaces:** all portal routes.
- Q2 **Toggle behavior:** manual only (no OS auto-detect).
- Q3 **Default theme:** `light` for new users; existing users get `light` via NOT NULL DEFAULT.
- Q4 **Persistence:** DB synced per-user, not localStorage.
- Q5 **Toggle placement:** user-menu dropdown.
- Q6 **Audit strategy:** audit-then-ship — fix all hardcoded colors before flipping the toggle on.
- Q7 **First-paint behavior:** always light until preference loads. Flash on first authenticated paint is accepted.
- Q8 **Toggle label:** "Dark Mode" (English).

**Out of scope** (explicitly):
- Per-tab override.
- `prefers-color-scheme` auto-detect.
- Third theme (high-contrast, sepia, etc.).
- Charting / data-viz palette tuning beyond what the existing `accent`/`success`/`warning`/`danger`/`info` tokens already cover.
- Print or PDF export styling.
- E-mail digest / external notification styling.

- [ ] **Step 4: Write `handler.ts`**

```ts
// api/src/me/set-theme/handler.ts
import type { Db } from '../../db/connection.js';
import type { Session } from '../../auth/session.js';
import type { SetThemeBody, SetThemeResponse } from './schemas.js';

export async function handleSetTheme(
  db: Db,
  session: Session,
  body: SetThemeBody,
): Promise<{ status: 200; body: SetThemeResponse }> {
  await db
    .updateTable('private_core.app_users')
    .set({ theme_preference: body.theme })
    .where('user_id', '=', session.user_id)
    .execute();
  return { status: 200, body: { ok: true, theme: body.theme } };
}
```

- [ ] **Step 5: Write `route.ts`**

```ts
// api/src/me/set-theme/route.ts
import type { FastifyInstance, FastifyRequest, FastifyReply } from 'fastify';
import type { Db } from '../../db/connection.js';
import type { Session } from '../../auth/session.js';
import { AuthError } from '../../auth/session.js';
import { SetThemeBodySchema } from './schemas.js';
import { handleSetTheme } from './handler.js';

export interface RouteDeps {
  db: Db;
  extractSession: (req: FastifyRequest) => Promise<Session>;
}

export function registerSetThemeRoute(app: FastifyInstance, deps: RouteDeps): void {
  app.post('/api/v1/mutations/me/set-theme', async (req: FastifyRequest, reply: FastifyReply) => {
    let session: Session;
    try {
      session = await deps.extractSession(req);
    } catch (err) {
      if (err instanceof AuthError) return reply.code(err.statusCode).send({ error: err.message });
      throw err;
    }
    const parsed = SetThemeBodySchema.safeParse(req.body);
    if (!parsed.success) {
      return reply.code(400).send({ error: 'VALIDATION_FAILED', details: parsed.error.flatten() });
    }
    const result = await handleSetTheme(deps.db, session, parsed.data);
    return reply.code(result.status).send(result.body);
  });
}
```

- [ ] **Step 1: Write the provider**

```tsx
// src/lib/theme/ThemeProvider.tsx
"use client";

import { createContext, useContext, useEffect, useState, useCallback, type ReactNode } from "react";
import { useSession } from "@/lib/auth/session-provider";

type Theme = "light" | "dark";

interface ThemeContextValue {
  theme: Theme;
  setTheme: (next: Theme) => void;
  toggle: () => void;
}

const ThemeContext = createContext<ThemeContextValue | null>(null);

function applyClass(theme: Theme) {
  const root = document.documentElement;
  if (theme === "dark") root.classList.add("dark");
  else root.classList.remove("dark");
}

export function ThemeProvider({ children }: { children: ReactNode }) {
  const { session, isLoading } = useSession();
  const [theme, setThemeState] = useState<Theme>("light");

  // Apply preference once session is loaded.
  useEffect(() => {
    if (isLoading) return;
    const initial: Theme = session?.theme_preference === "dark" ? "dark" : "light";
    setThemeState(initial);
    applyClass(initial);
  }, [isLoading, session?.theme_preference]);

  const setTheme = useCallback((next: Theme) => {
    setThemeState(next);
    applyClass(next);
    fetch("/api/me/set-theme", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ theme: next }),
    }).catch(() => {
      // best-effort: revert on hard failure
      const prev: Theme = next === "dark" ? "light" : "dark";
      setThemeState(prev);
      applyClass(prev);
    });
  }, []);

  const toggle = useCallback(() => {
    setTheme(theme === "dark" ? "light" : "dark");
  }, [theme, setTheme]);

  return (
    <ThemeContext.Provider value={{ theme, setTheme, toggle }}>
      {children}
    </ThemeContext.Provider>
  );
}

export function useTheme(): ThemeContextValue {
  const ctx = useContext(ThemeContext);
  if (!ctx) throw new Error("useTheme must be used inside ThemeProvider");
  return ctx;
}
```
