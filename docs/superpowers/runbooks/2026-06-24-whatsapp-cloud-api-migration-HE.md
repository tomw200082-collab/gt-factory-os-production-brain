# מדריך הגירת מספר וואטסאפ ל‑WhatsApp Cloud API (למען בוט ההזמנות)

**תאריך:** 24/06/2026 · **למי:** Tom · **מטרה:** להעביר את מספר הוואטסאפ העסקי שלך מאפליקציית
**WhatsApp Business** הרגילה אל **WhatsApp Cloud API** של Meta — כדי שבוט יוכל לקרוא הודעות ולענות.
זה השלב היחיד בכל הפרויקט שרק אתה יכול לעשות, והוא הכי ארוך (תלוי באישור של Meta), לכן כדאי להתחיל בו עכשיו.

> **לינק להתחלה (השמור הזה):** https://business.facebook.com/wa/manage/ — זה ה‑WhatsApp Manager.
> אם הוא מבקש, היכנס דרך **Meta for Developers**: https://developers.facebook.com/

---

## ⚠️ קודם כל — החלטה אחת חשובה (החלטה 0): איזה מספר?

הגירה של מספר מאפליקציית WhatsApp Business אל ה‑API **מנתקת אותו מהאפליקציה** — לא תוכל יותר לפתוח
את הצ'אטים של אותו מספר באפליקציה הרגילה, וההיסטוריה לא עוברת. לכן יש שתי דרכים:

| | מספר A — להגר את המספר הקיים | מספר B — מספר חדש ייעודי לבוט |
|---|---|---|
| הלקוחות | ממשיכים לכתוב לאותו מספר שהם מכירים | צריך להפנות אותם למספר חדש |
| אפליקציית WhatsApp Business | **תפסיק לעבוד** עבור המספר הזה | ממשיכה לעבוד כרגיל לכל מה שאתה עושה היום |
| היסטוריית צ'אטים | לא עוברת (גבה לפני!) | לא רלוונטי |
| הקטלוג | עובר עם המספר (יושב ב‑Commerce Manager) | צריך לשייך/לשכפל קטלוג |
| מתי מתאים | אם המספר הזה משמש *רק* לקבלת הזמנות | אם צוות עובד היום על המספר הזה והגיוני לשמור אותו |

**ההמלצה שלי:** אם המספר שהלקוחות שולחים אליו הזמנות הוא ייעודי (לא מספר שאתה והצוות עובדים עליו כל
היום לדברים אחרים) → **מספר A (להגר את הקיים)**, כי הלקוחות לא צריכים לשנות כלום. אם הוא מספר חי
שצוות עובד עליו → **מספר B (חדש)** ואז להפנות אליו את הלקוחות בהדרגה.

👈 **תחליט A או B לפני שמתחילים.** כל השלבים זהים; ההבדל היחיד הוא איזה מספר אתה רושם בשלב 4.
**אם בחרת A — גבה קודם את הצ'אטים של המספר (הגדרות → צ'אטים → גיבוי).**

---

## מה צריך להכין לפני שמתחילים (10 דקות)

1. **חשבון פייסבוק אישי** שאיתו אתה מנהל את העסק (משמש כניהול בלבד; הלקוחות לא רואים אותו).
2. **מסמכי עסק לאימות** (Business Verification): ח.פ / תעודת עוסק, וכתובת + טלפון של העסק שמופיעים
   על מסמך רשמי (חשבונית/חשבון ארנונה/אישור ניהול חשבון בנק). Meta בודקת שהעסק אמיתי.
3. **גישה למספר הטלפון** שאתה רושם — צריך לקבל בו SMS או שיחה לקוד אימות חד‑פעמי.
4. **שם תצוגה לעסק** בוואטסאפ (למשל "GT Everyday" / "GT אוורידיי") — Meta מאשרת אותו.

## השלבים — לפי הסדר

### שלב 1 — חשבון Meta Business (Business Manager)
1. היכנס ל‑https://business.facebook.com/
2. אם אין לך עדיין "תיק עסקי" (Business Portfolio) — צור אחד: שם העסק, האימייל שלך.
3. ודא שאתה **Admin** בתיק העסקי.

### שלב 2 — אימות העסק (Business Verification) ⏳ *זה החלק שלוקח זמן*
1. ב‑Business Manager → **Settings (גלגל שיניים)** → **Business Info / Security Center**.
2. לחץ **Start Verification** והעלה את מסמכי העסק (שלב "מה צריך להכין", סעיף 2).
3. שלח לאישור. **Meta בדרך כלל עונה תוך 1–2 ימי עסקים** (לפעמים מהר יותר, לפעמים מבקשת מסמך נוסף).
4. אפשר להמשיך לשלבים 3–6 **במקביל** בזמן שזה ממתין לאישור — רק השימוש המלא/הסרת מגבלות דורש אימות.

### שלב 3 — אפליקציה ב‑Meta for Developers + מוצר WhatsApp
1. היכנס ל‑https://developers.facebook.com/ → **My Apps** → **Create App**.
2. סוג האפליקציה: בחר **Business**. תן שם (למשל "GT Order Intake"), ושייך אותה לתיק העסקי משלב 1.
3. בתוך האפליקציה → **Add Product** → בחר **WhatsApp** → **Set up**.
4. כעת ייפתח מסך "WhatsApp → API Setup". כאן Meta יוצרת לך אוטומטית **מספר בדיקה** (test number)
   ו‑**WABA** (WhatsApp Business Account). **אל תשתמש במספר הבדיקה לייצור** — אנחנו נרשום את המספר
   האמיתי בשלב הבא.

### שלב 4 — להוסיף/להגר את המספר האמיתי (כאן נכנסת החלטה A/B)
1. עבור ל‑**WhatsApp Manager**: https://business.facebook.com/wa/manage/ (או מתוך מסך ה‑API Setup →
   "Add phone number").
2. לחץ **Add phone number** והזן את המספר שבחרת (A = הקיים, B = החדש), כולל קידומת בינלאומית
   (לדוגמה 972 במקום ה‑0 הראשון).
3. **אם בחרת A (מספר קיים מהאפליקציה):** Meta תזהה שהמספר רשום ב‑WhatsApp Business app ותציג אזהרה
   שהמספר ינותק מהאפליקציה. אשר (אחרי שגיבית צ'אטים).
4. בחר אימות ב‑**SMS** או **שיחה**, קבל את הקוד והזן אותו.

### שלב 5 — רישום המספר + קוד דו‑שלבי (2FA PIN)
1. במהלך הרישום Meta תבקש להגדיר **PIN בן 6 ספרות** (Two‑Step Verification) למספר.
2. **רשום את ה‑PIN ושמור אותו** — צריך אותו אם רושמים מחדש את המספר בעתיד. (לא להדביק לי אותו בצ'אט.)

### שלב 6 — שם תצוגה ואישורו
1. ב‑WhatsApp Manager → המספר → **Profile / Display name** → הזן את שם התצוגה (משלב ההכנה).
2. שם התצוגה עובר אישור של Meta (בדרך כלל מהיר). הוא מה שהלקוחות יראו ככותרת הצ'אט.

### שלב 7 — טוקן קבוע + המזהים (זה מה שאני צריך כדי לחבר את הבוט)
המסך "API Setup" נותן טוקן **זמני** (24 שעות) — לא מספיק. צריך טוקן **קבוע** דרך System User:
1. Business Manager → **Settings** → **Users** → **System Users** → **Add** → צור משתמש מערכת
   (Admin) בשם למשל "order-intake-bot".
2. לחץ **Add Assets** → שייך אליו את האפליקציה ואת ה‑WABA עם הרשאות מלאות.
3. לחץ **Generate New Token** → בחר את האפליקציה → סמן את ההרשאות **whatsapp_business_messaging**
   ו‑**whatsapp_business_management** → צור טוקן. **זה הטוקן הקבוע.**
4. אסוף את שלושת הפרטים האלה:
   - **Phone Number ID** (מתוך API Setup / WhatsApp Manager)
   - **WhatsApp Business Account ID (WABA ID)**
   - **App ID** + **App Secret** (Settings → Basic של האפליקציה)

> 🔐 **חשוב — אבטחה:** **אל תדביק לי את הטוקן/הסוד בצ'אט.** כשנגיע לבנייה, תשים אותם בקובץ
> `gt-factory-os/.env` בלבד (כמו שאר הסודות של המערכת). לי מספיק לדעת ש**יש** לך אותם. את ה‑IDs
> שאינם סודיים (Phone Number ID, WABA ID, App ID) אפשר לשלוח.

### שלב 8 — הקטלוג (אם בחרת A, הוא עובר; כדאי לוודא)
1. היכנס ל‑Commerce Manager: https://business.facebook.com/commerce/
2. ודא שהקטלוג של המוצרים משויך ל‑WABA הנכון. אם בחרת B (מספר חדש) — שייך/שכפל את הקטלוג ל‑WABA החדש.
3. הקטלוג לא חובה לבוט (הבוט מבין טקסט חופשי), אבל טוב שיהיה מסונכרן.

## כמה זמן זה לוקח / איפה נתקעים בדרך כלל
- **אימות עסק (שלב 2):** 1–2 ימי עסקים בממוצע — זה הצוואר בקבוק. התחל אותו **ראשון**.
- שאר השלבים: כשעה עבודה נטו, מתחלקת על פני היום.
- **תקיעות נפוצה:** Meta מבקשת מסמך עסק נוסף/ברור יותר → פשוט העלה שוב. שם התצוגה נדחה → בחר שם
  שמתאר את העסק ולא גנרי.

## מה לשלוח לי כשסיימת
שלח לי בצ'אט (לא סודי): **"אימות עסק: אושר/ממתין"**, ה‑**Phone Number ID**, ה‑**WABA ID**, וה‑**App ID**.
את ה‑**App Secret** ואת ה‑**Token** — תשמור ל‑`.env` בלבד, אל תדביק כאן. ברגע שהאימות אושר והמספר רשום,
אנחנו ב‑G2 הושלם, ואפשר לחבר את הבוט.
