# GT — מפת התפעול (operational map artifact)

מפה תפעולית חיה של GT Everyday, בעברית (RTL), מותאמת לנייד — לשימוש היומי של תום וגם להצגה לאלכס.
המפה היא **תצוגה** של מקורות־האמת בריפו; היא לעולם לא אמת עצמאית.

- **כתובת האמון (live URL):** https://claude.ai/code/artifact/0516e663-3bfb-47c7-8503-ec342fe95296
- **קובץ המקור:** `index.html` (בתיקייה הזו) — בדיוק הבייטים שמתפרסמים.
- **סטטוס:** פרטי עד ששיתוף נעשה ידנית מתפריט השיתוף של הארטיפקט.
- **Favicon:** 🏭 · **כותרת:** `GT — מפת התפעול` — **לא לשנות אף פעם** בפרסום מחדש.

## השכבות (v2, 23.7.2026 — אחרי סבב האודיט)
`היום` (טאב ראשון, מחושב לפי יום השבוע) · `1 המפה` (זרימת־על כקו מטרו: קו ראשי + 3 קווי־לולאה
בצבע הבעלים + ״אתה נמצא כאן״ לפי השעה) · `2 אנשים` (כולל 3 כללי ברזל לכל אחד) · `3 השעון`
(השורה של השעה הנוכחית מסומנת) · `4 ספי ₪` (סכומים גדולים + סולם ציוד אחד) · `5 תקלות`
(״משהו קרה? מה עושים״ — טבלת החריגות מהפלייבוק) · `6 המערכת` · `7 מדידה` (כולל ״מה עוד לא סגור״).
טאב־בר (נייד): היום · המפה · אנשים · שעון · ספי ₪ · תקלות · מדידה. ״המערכת״ נגישה מרשת־הקפיצה שבמסך היום.
`מצב הצגה` (מתג בכותרת, נשמר ב־localStorage) = מתג צפיפות לאלכס: נפתח על המפה,
מסתיר את היום/תקלות/מערכת ואת בלוק ״מה עוד לא סגור״, ומקצר את כרטיסי האנשים.
שפה: עברית מדוברת — יעדים במילים (״לפחות 80%״, ״עד 7 ימים״), בלי ‎≥/≤‎ (מתהפכים ב־RTL),
בלי ז׳רגון מערכת (plan-vs-actual → ״תוכנית מול ביצוע״). גופן: Heebo (OFL) מוטמע כ־data URI.
יושר תפעולי: תזכורת שבת 18:00 ללקוחות מסומנת ״מתוכנן — עוד לא פועל״ (אין טריגר כזה עדיין;
מופעל רק באישור תום); דוח 13:45 = טאב ״מחר״ בלוח — אין שליחה אוטומטית עדיין.

  חבילת הדפסה, קבלה מחשבונית): מה כל אחד עושה, מתי, מה קורא/כותב + דיאגרמת ״איך הם משתלבים״ (4 מקצבים).
- **המערכות** — LionWheel · Shopify · חשבונית ירוקה · Factory OS · Make: מקור־אמת, מה עושים, וכללים־לתעד

  מקורות: [Standardized Work](https://artoflean.com/reference/standard-work/) + [TWI Job Instruction](https://artoflean.com/reference/job-instruction/).
  **v4 (23.7):** הדף הוא כעת **משטח כתיבה שבועי** של תום — גיבור ״כתוב כאן איך עושים כל דבר״ + התבנית הגלויה
  + כפתורי ״משימה משלך״ ו״ייצא את מה שכתבת״. ליקוט וקבלת סחורה נשארים כדוגמה מלאה; השאר נכתב במהלך השבוע,

- **v4 העמקות:** דף הסקילים — ״העיקרון״ (§G) לכל סקיל; דף המערכות — ״מתחת למכסה״ עם סמנטיקת מקור־האמת

## לכידה בתוך הארטיפקט — ״רשום מחשבה״
כפתור צף (מוסתר במצב הצגה) → גיליון: טקסט + תגית (רעיון/סקיל/מערכת/רצפה/כללי) → נשמר ב־`localStorage`
(מפתח `gt-map-notes`) **במכשיר בלבד**. שני גשרים החוצה: **״העתק הכל״** (clipboard) ו־**״ייצא Markdown״**
(יכולת `downloads` — `window.claude.downloads.save`). **אין סנכרון אוטומטי לריפו/לקלוד — זה לא קיים בפלטפורמה.**
הזרימה הכנה: לוכד → מעתיק/מייצא → מדביק לקלוד בצ׳אט או ל־`inbox/` של Obsidian → משם נכנס ומבוצע.
כפתורי ״רשום״ שליד כל פער (מערכות/רצפה) פותחים את הלכידה עם טקסט ותגית מוכנים.

## חוזה הרענון השבועי (binding)

**כל המספרים שמתעדכנים שבועית יושבים בבלוק אחד בלבד** בראש הסקריפט ב־`index.html`:

```js
const WEEKLY_DATA = {          // WEEKLY-REFRESH-BLOCK — routine: edit ONLY here
  as_of: "2026-07-23",
  ...
};
```

- שאר העמוד **קורא בלבד** מ־`WEEKLY_DATA`. חותמת ״נכון ל־״ בכותרת נגזרת מ־`as_of`.
- ברענון שבועי — **עורכים אך ורק את הבלוק הזה** (מספרי CCI, בסיסי ה־KPI, שבוע ההטמעה הנוכחי, `as_of`).
  אין לגעת בשום קוד אחר בעמוד.
- מספרים שאין להם נתון נכתבים `"טרם"` / `"טרם נמדד"` — לא ממציאים.

## הערות טכניות

- הכול inline (CSP-safe): אפס CDN, אפס גופנים חיצוניים, אפס `fetch`. כל האינטראקציה היא JS מקומי.
- עמוד סטטי — לא הוגדרו יכולות ריצה (capabilities). אין צ׳אט בתוך העמוד: שיפורים עוברים בצ׳אט עם
  קלוד ומתקפלים לעדכון של ראשון.
- תמיכה בבהיר/כהה (`prefers-color-scheme` + `:root[data-theme=...]`). RTL מלא. עוצב ב־390px.
- `todayModel(dayIndex)` — פונקציה טהורה + בדיקה עצמית ל־7 הימים (מוצגת בפוטר: ״בדיקת ימים 7/7 ✓״).
