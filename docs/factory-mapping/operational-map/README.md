# GT — מפת התפעול (operational map artifact)

מפה תפעולית חיה של GT Everyday, בעברית (RTL), מותאמת לנייד — לשימוש היומי של תום וגם להצגה לאלכס.
המפה היא **תצוגה** של מקורות־האמת בריפו; היא לעולם לא אמת עצמאית.

- **כתובת האמון (live URL):** https://claude.ai/code/artifact/0516e663-3bfb-47c7-8503-ec342fe95296
- **קובץ המקור:** `index.html` (בתיקייה הזו) — בדיוק הבייטים שמתפרסמים.
- **סטטוס:** פרטי עד ששיתוף נעשה ידנית מתפריט השיתוף של הארטיפקט.
- **Favicon:** 🏭 · **כותרת:** `GT — מפת התפעול` — **לא לשנות אף פעם** בפרסום מחדש.

## שבע השכבות
`היום` (רצועת פתיחה, מחושבת לפי יום השבוע) · `1 זרימת־על` · `2 אנשים` · `3 השעון` ·
`4 ספי ₪` · `5 המערכת` · `6 מדידה` · `7 פתוחים`.
`מצב הצגה` (מתג בכותרת, נשמר ב־localStorage) = מתג צפיפות לאלכס: נפתח על זרימת־העל,
מציג אנשים/שעון מקוצרים + מדידה, ומסתיר את פריטים־פתוחים, פרטי־מערכת טכניים ורצועת ״היום״.

## חוזה הרענון השבועי (binding)

**כל המספרים שמתעדכנים שבועית יושבים בבלוק אחד בלבד** בראש הסקריפט ב־`index.html`:

```js
const WEEKLY_DATA = {          // WEEKLY-REFRESH-BLOCK — routine: edit ONLY here
  as_of: "2026-07-23",
  ...
};
```

- שאר העמוד **קורא בלבד** מ־`WEEKLY_DATA`. חותמת ״נכון ל־״ בכותרת נגזרת מ־`as_of`.
- ברענון שבועי — **עורכים אך ורק את הבלוק הזה** (מספרי CCI, בסיסי ה־KPI, שבוע ההטמעה הנוכחי, `as_of`).
  אין לגעת בשום קוד אחר בעמוד.
- מספרים שאין להם נתון נכתבים `"טרם"` / `"טרם נמדד"` — לא ממציאים.

## איך לפרסם מחדש (מסשן אחר — למשל רוטינת ה־Scorecard של ראשון)

1. עדכנו את `WEEKLY_DATA` ב־`index.html` (הבלוק בלבד), כולל `as_of` חדש.
2. קראו לכלי **Artifact** עם `file_path` של הקובץ הזה **ו־`url` של הארטיפקט הקיים**
   כדי לפרסם לאותה כתובת:
   - `file_path`: `docs/factory-mapping/operational-map/index.html`
   - `url`: `https://claude.ai/code/artifact/0516e663-3bfb-47c7-8503-ec342fe95296`
   - `favicon`: `🏭` · `title`: `GT — מפת התפעול` (יציבים — לא לשנות)
   > בלי פרמטר `url` מסשן שלא פרסם את הארטיפקט הזה — ייווצר URL חדש. תמיד להעביר `url`.
3. הקומיטו את השינוי ב־`index.html` על הברנץ׳ המיועד ופתחו PR.

## הערות טכניות

- הכול inline (CSP-safe): אפס CDN, אפס גופנים חיצוניים, אפס `fetch`. כל האינטראקציה היא JS מקומי.
- עמוד סטטי — לא הוגדרו יכולות ריצה (capabilities). אין צ׳אט בתוך העמוד: שיפורים עוברים בצ׳אט עם
  קלוד ומתקפלים לעדכון של ראשון.
- תמיכה בבהיר/כהה (`prefers-color-scheme` + `:root[data-theme=...]`). RTL מלא. עוצב ב־390px.
- `todayModel(dayIndex)` — פונקציה טהורה + בדיקה עצמית ל־7 הימים (מוצגת בפוטר: ״בדיקת ימים 7/7 ✓״).
