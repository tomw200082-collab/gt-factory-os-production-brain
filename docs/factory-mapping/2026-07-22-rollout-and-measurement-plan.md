## מדד-על: "מדד עלות הכאוס" (₪/שבוע)

מספר אחד שטום (ואלכס) רואים כל ראשון. הגדרה מדויקת:

**CCI = A + B + C**

| רכיב | הגדרה מדויקת | מקור |
|---|---|---|
| **A — זיכויים** | סך ₪ הזיכויים שהופקו בשבוע (כולם, לא רק פערי ליקוט) | `/credit-tracking` |
| **B — קניות חירום** | סך ₪ הזמנות רכש שנוצרו **ובוצעו** מחוץ לסשן הרכש השבועי: PO ללא שיוך לסשן חמישי, או שנוצר+בוצע באותו יום שאינו חמישי | purchase_orders |
| **C — קנס תור תקוע** | מס' הזמנות ב-APPROVED_TO_ORDER מעל יום עסקים בצילום חמישי 15:50 × ‏250 ₪ (קנס נומינלי — ממיר עיכוב לשקלים כדי שהמדד יישאר מספר אחד) | תור הרכש |

- בייסליין נמדד בשבוע 0 (ידוע כבר: 6 זומבים ב-16.7 = ‏1,500 ₪ ברכיב C בלבד).
- **מדד תוצאה, לא שער מעבר** — עוקבים אחרי מגמה; שערי המעבר הם מדדי אימוץ (למטה). יעד רבעון: ירידה ≥50% מהבייסליין.
