# GT Factory OS — Gap Registry

> **Authority:** Persistent ranked list of all known operational gaps. Updated after every audit and tranche close.
> **Schema per entry:** ID | Severity | Layer | Description | Blocked by | Status | First detected | Closed

Severity scale:
- **P0** — Blocks any operator from performing their primary daily job
- **P1** — Operators can work but require significant manual workaround or developer help
- **P2** — Works but slower, less safe, or less clear than it should be
- **P3** — Polish, optimization, advanced feature, or stretch goal
